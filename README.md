## 📁 Dataset Overview

**Type:** Retail / E-commerce structured tabular data at the customer transaction level.

| Feature Type | Columns |
|---|---|
| Numeric | Age, Purchase Amount, Previous Purchases |
| Categorical | Category, Payment Method, Season |

### Why It Matters
This analysis helps businesses:
- Identify high-value customers
- Understand purchase patterns
- Optimize discount strategies
- Improve marketing campaigns
- Increase customer lifetime value (CLV)

## 🚀 Business Recommendations

1. **Double down on Electronics** — it drives 49% of revenue, but improve quality/support to fix the low ratings
2. **Expand subscription programs** — subscribers spend 63% more; target the 2,763 repeat buyers not yet subscribed
3. **Focus marketing on 60+ customers** — they generate nearly half of all revenue
4. **Promote Express shipping** — it correlates with higher order values
5. **Target Spring campaigns** — highest revenue season at $243K
